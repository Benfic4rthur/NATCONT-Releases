# NATCONT Releases

Repositório público usado exclusivamente para distribuir versões do aplicativo Natcont para macOS.

Este repositório não contém o código-fonte do sistema, banco de dados, fotos, comprovantes, backups ou credenciais.

As releases publicadas aqui podem conter somente artefatos de distribuição e metadados do atualizador, como:

- `Natcont-<versão>-mac-x64.dmg`
- `Natcont-<versão>-mac-x64.zip`
- `latest-mac.yml`
- arquivos de assinatura/metadados gerados pelo empacotamento

O código-fonte permanece no repositório privado do Natcont.
